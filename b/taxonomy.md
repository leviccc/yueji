# 关系类型受控词表 v1

用于把模型抽取的关系标签归一到少量可复用类型，并作为人工标注（gold）与预测（predictions）的共同标签集。标注单位为一条关系断言：`(book_id, progress_chapter, source, target, relation, directed, action)`，其中 `progress_chapter` 是读者获知该关系的章节，不是故事发生时间。

## 方向约定

- 亲属类一律无向（`directed=false`），因为血缘关系不因叙述方向改变。
- 社交、态度、角色类有向（`directed=true`），源→目标表示作用方向；方向相反的断言视为不同关系（如「我 怀疑 他」≠「他 怀疑 我」）。
- `action` 仍保留 README 定义的 `assert` / `end`；本词表默认 `assert`，明确结束时才标 `end`。

## 一、亲属（无向）

| 标签 | 定义 | 示例 |
|---|---|---|
| 祖孙 | 祖辈与孙辈 | 祖母—魏连殳 |
| 亲子 | 父母与子女 | 父亲—魏连殳、母亲—魏连殳 |
| 继亲 | 继父母与继子女等非生关系 | 祖母—父亲（祖母是父亲的继母） |
| 兄弟 | 兄弟、堂兄弟、从堂兄弟 | 堂兄—魏连殳、连殳的从堂兄弟—魏连殳 |
| 叔侄 | 叔伯与侄辈 | 远房侄子—魏连殳 |
| 过继 | 送养方与收养方的过继关系或过继提议 | 堂兄—魏连殳（欲将儿子过继给他） |
| 其他亲属 | 无法归入上述类别的亲属关系 | 族人、远亲 |

| 标签 | 定义 | 示例 |
|---|---|---|
| 其他 | 无法归入上述类型、但被模型作为关系输出的断言（多为一次性事件或身份指认） | 十三大人—魏连殳（询问存款）、女工—祖母（指认画像） |

## 六、归一化规则

1. **同义合并**：模型原始标签按下表映射；同一对人物、同一标签、同一获知章节只保留一条，重复断言不重复计数。
2. **开发集评测过滤**：在《孤独者》的专用评测导出中，一次性动作（询问存款、回信意愿、指认画像）归一为「其他」后被过滤；此规则不自动修改网页图谱，图谱显示人工接受的记录。保留该桶是为了在归一化阶段显式识别。
3. **不猜指代**：引语中的「我」若指小说人物而非叙述者，必须按语境归到实际人物，否则视为错误；gold 与 predictions 都按各自依据填写，不做对齐修正。
4. **合并与别名不影响标签**：人物合并和别名只改变节点 ID 的映射，不改变关系类型。
5. **新增标签的门槛**：同一语义在语料中出现至少两次、且无法归入现有标签时才新增，避免标签爆炸。
